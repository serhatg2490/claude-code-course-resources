## Task: Implement server-side auth helpers - 2026-09-30

Completed:
- `lib/auth.ts`:

  - `getSession()`: `auth.api.getSession({ headers: await headers() })` → `{ session, user } | null`. Wrapped in React

  - `requireAuth()`: returns the non-null session, or `redirect(SIGN_IN_PATH)` (`/authenticate`). `redirect()` returns

- A factory rather than helpers bound directly to the `auth` singleton: `bun test` shares one module registry across files,
